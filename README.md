# 🏁 MAP CAR RACE

**世界中のどこでもサーキットになる、three.js 製 3D カーレース。**
場所を指定すると、OpenStreetMap の *本物の道路* から周回コースを自動生成し、その街並み（建物・公園・水辺）の中を走れます。

## 遊び方

1. `index.html` を静的サーバーで開く（ES Modules を使うため `file://` ではなく HTTP で配信してください）
   ```bash
   python3 -m http.server 8000   # → http://localhost:8000
   ```
2. 場所を検索 / おすすめスポットを選択 / 📍現在地
3. コース長・時間帯（昼 / 夕方 / 夜）・周回数・ライバル数を選んで **コースを生成してレース**
4. 生成されたコースを俯瞰プレビュー → **スタート！**（「別のコース」で同じ場所の別ルートを再生成）

URL パラメータでも指定できます: `?lat=35.6595&lon=139.7005&name=渋谷&theme=night&len=4000&laps=3&auto=1`
（`?demo=1` でオフライン用の手続き生成都市）

## 操作

| 操作 | キー |
|---|---|
| アクセル / ブレーキ(バック) | `W` `↑` / `S` `↓` |
| ハンドル | `A` `D` / `←` `→` |
| ドリフト(ハンドブレーキ) | `Space` |
| ニトロ | `Shift`（ドリフトで充填、コース上のブーストパッドでも加速） |
| カメラ切替 | `C` |
| コース復帰 | `R` |
| ポーズ / ミュート | `P` `Esc` / `M` |

ゲームパッド（スティック / RT / LT / A=ニトロ / B,X=ドリフト / Y=カメラ）とタッチ操作にも対応。

## 技術メモ

- **地図**: Nominatim でジオコーディング → Overpass API で道路・建物・公園・水域を取得し、中心点を原点とするメートル座標へ投影。
- **コース生成** (`js/course.js`): 道路をグラフ化し、「行き」と「帰り」を別ルートで取る周回を多数生成。ルート重複・自己交差・Uターン・近接を減点して最良の1本を選び、曲率制約付きの平滑化 → Catmull-Rom で等間隔サンプル化。
- **描画** (`js/world.js`): 建物をチャンク結合して押し出し（窓テクスチャ＋夜は発光窓）、PBR 路面・縁石・ウォール・看板・ゲート・街灯、昼夜対応のシェーダー空（雲・星）、PMREM 環境反射、影、ブルーム、速度ブラー/色収差。
- **車** (`js/car.js`): 断面ロフトによるプロシージャル車体、アーケード物理（グリップ限界・ドリフト・壁/車体衝突）、AI（速度プロファイル＋ラバーバンド＋回避）。
- 外部アセット不要（音もすべて WebAudio 合成）。three.js は `vendor/` に同梱。

## ランドマーク

OpenStreetMap の観光名所・史跡・塔・大聖堂・スタジアムなどを検出し、コース近くのものにビーコンと名前ラベルを立て、ミニマップに◆で表示します。近くを通ると名前が表示されます。

## GitHub Pages で公開する

リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にすると、`main` ブランチへの push のたびに `.github/workflows/pages.yml` が `index.html` / `css` / `js` / `vendor` を公開します。公開URLは `https://<ユーザー名>.github.io/<リポジトリ名>/` です。
